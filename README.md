# 扫光标题制作器

上传任意图片（PNG / JPG / WebP），支持 **AI 一键抠图** 与 **纯色背景抠图**，在线预览并导出带「经典扫光 / 金色流光」特效的动画标题（WebM / GIF / 透明 PNG）。所有处理都在浏览器本地完成，图片不会上传。

## 使用
1. 打开页面（见上方 GitHub Pages 链接）
2. 上传图片：支持 PNG / JPG / WebP
   - 透明底 PNG：直接使用
   - 普通 JPG / WebP / 带背景 PNG：
     - 「✨ AI 抠图」一键去除背景（本地运行 RMBG-1.4 模型，适合背景复杂图，自动恢复文字内部 + 去描边）
     - 「🎨 纯色抠图」按背景色抠图（无需模型、秒出，适合深色/纯色底标题，白色文字内部 100% 保留）
3. 抠图后可用「↺ 恢复原图」还原
4. 选择特效：
   - 经典扫光：柔和斜向光带，从左到右快速扫过
   - 金色流光：宽幅暖金光带缓慢流过 + 标题大小缩放脉冲
5. 调节光带宽度、亮度、角度、缩放幅度、扫过/停顿时长/整体循环（三者独立不联动）
6. 导出：↓ GIF（循环动图，自动压缩静止帧）/ ↓ WebM（透明背景）/ ↓ 透明 PNG

## AI 抠图说明
- 模型为 `briaai/RMBG-1.4`（ONNX q8 量化，约 44MB），与页面、Transformers.js 库及 wasm 全部托管在本仓库同源目录（`models/`、`lib/`），不依赖 huggingface.co，也不依赖任何外部 CDN
- 首次点击抠图需下载模型（约 44MB），之后浏览器自动缓存，秒开
- 抠图后自动做去描边处理：去淡边、收缩半透明带、边缘颜色去色晕，保证干净无白边
- AI 掩码会做「文字内部恢复」：被模型误删的白/亮色字芯自动补回，字母镂空（如 O / A 的孔）仍保持透明

## 技术说明
- 抠图引擎：Transformers.js + RMBG-1.4 ONNX，全部自托管（IIFE 构建，浏览器可直接识别）
- GIF 由内置编码器生成（中位切分 256 色 + LZW）
- 导出 WebM 建议使用 Chrome / Edge
