# 扫光标题制作器

输入标题文案或上传透明底 PNG，在线预览并导出带「经典扫光 / 金属爆闪 / 金色流光 / 红金流光」特效的动画标题（WebM / GIF / 透明 PNG）。所有处理都在浏览器本地完成，图片不会上传。

## 使用
1. 打开页面（见上方 GitHub Pages 链接）
2. 输入主标题/副标题 → 选画布尺寸 → 「✦ 生成标题」；或上传透明底 PNG
3. 选择特效：
   - 经典扫光：柔和斜向光带，从左到右快速扫过
   - 金属爆闪：中央金白爆闪，光带向左右分裂 + 字体缩放脉冲
   - 金色流光：宽幅暖金光带缓慢流过 + 标题大小缩放脉冲
   - 红金流光：复刻短视频红底金白字标题——宽亮光带从左向右扫过，掠过时横幅泛白、文字增亮，右端停留后衰减，周期约 5 秒
4. 导出：↓ GIF（循环动图，自动压缩静止帧）/ ↓ WebM（透明背景）/ ↓ 透明 PNG

## 技术说明
- 单文件 HTML，无外部依赖，可离线使用
- GIF 由内置编码器生成（中位切分 256 色 + LZW）
- 导出 WebM 建议使用 Chrome / Edge
