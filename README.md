# 扫光标题制作器

上传任意图片（PNG / JPG / WebP），支持 **AI 一键抠图** 与 **纯色背景抠图**，在线预览并导出带「经典扫光 / 金色流光」特效的动画标题（WebM / GIF / 透明 PNG）。所有处理都在浏览器本地完成，图片不会上传。

## 使用
1. 打开页面（见上方 GitHub Pages 链接）
2. 上传图片：支持 PNG / JPG / WebP
   - 透明底 PNG：直接使用
   - 普通 JPG / WebP / 带背景 PNG：
     - 「✨ AI 抠图」一键去除背景（本地运行 ISNet 神经网络抠图引擎，适合任意背景，含渐变/复杂背景；自动恢复文字内部 + 去描边）
     - 「🎨 纯色抠图」按背景色抠图（无需模型、秒出，适合深色/纯色底标题，白色文字内部 100% 保留）
3. 抠图后可用「↺ 恢复原图」还原
4. 选择特效：
   - 经典扫光：柔和斜向光带，从左到右快速扫过
   - 金色流光：宽幅暖金光带缓慢流过 + 标题大小缩放脉冲
5. 调节光带宽度、亮度、角度、缩放幅度、扫过/停顿时长/整体循环（三者独立不联动）
6. 导出：↓ GIF（循环动图，自动压缩静止帧）/ ↓ WebM（透明背景）/ ↓ 透明 PNG

## AI 抠图说明
- 抠图引擎为 IMG.LY 开源项目 `background-removal-js`（ISNet 神经网络 + 软边缘 alpha 抠像，浏览器内 ONNX Runtime 推理），模型与 wasm 全部自托管在本仓库同源目录（`models/imgly/`、`lib/`），不依赖任何外部 CDN
- 首次点击抠图需下载模型（约 88MB），之后浏览器自动缓存，秒开
- ISNet 是专门的抠像模型：白色文字内部 100% 保留（不会把白字扣穿）、边缘经过 alpha 抠像平滑无白边、渐变/复杂背景也能抠净
- 抠图后自动做后处理：文字内部恢复 + 去描边（去淡边、收缩半透明带、边缘颜色去色晕），保证干净无白边
- 在无跨域隔离（GitHub Pages）环境下自动降级为单线程推理，速度略慢但结果一致

## 技术说明
- 抠图引擎：`@imgly/background-removal`（ISNet ONNX + onnxruntime-web，esbuild 打成单文件 IIFE，全部自托管）
- GIF 由内置编码器生成（中位切分 256 色 + LZW）
- 导出 WebM 建议使用 Chrome / Edge
