# 扫光标题制作器

上传透明底 PNG，在线预览并导出带「经典扫光 / 金属爆闪 / 金色流光」特效的动画标题。所有处理都在浏览器本地完成，图片不会上传。

## 使用
1. 打开页面（见上方 GitHub Pages 链接）
2. 上传透明底 PNG（仅支持带透明通道的 PNG）
3. 选择特效：
   - 经典扫光：柔和斜向光带，从左到右快速扫过
   - 金属爆闪：中央金白爆闪，光带向左右分裂 + 字体缩放脉冲
   - 金色流光：宽幅暖金光带，缓慢从左侧流到右侧，在右端停留后循环，标题同步做大小缩放脉冲（每周期起伏两次）
4. 调节光带宽度、亮度、角度、缩放幅度、扫过/停顿时长
5. 导出 WebM（带透明背景）或下载透明底 PNG

## 技术说明
- 单文件 HTML，无外部依赖，可离线使用
- 导出 WebM 建议使用 Chrome / Edge
